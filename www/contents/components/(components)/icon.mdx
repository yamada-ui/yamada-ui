## Usage

:::code-group

```tsx [package]
import { GhostIcon } from "@yamada-ui/react"
```

```tsx [alias]
import { GhostIcon } from "@/components/ui"
```

```tsx [monorepo]
import { GhostIcon } from "@workspaces/ui"
```

:::

```tsx
<GhostIcon />
```

You can find all the icons we offer at [here](/icons).

:::tip
To display a waiting state, such as while data is loading, use [Loading](/docs/components/loading).
:::

:::tip
If users need to interact with an icon, use [IconButton](/docs/components/icon-button).
:::

### Using React Icons

When using [React Icons](https://react-icons.github.io/react-icons), set the component to `as`.

```ts
import { Icon } from "@yamada-ui/react"
import { FaRobot } from "react-icons/fa"
```

```tsx
<Icon as={FaRobot} />
```

### Using Lucide lab

When using [Lucide lab](https://github.com/lucide-icons/lucide-lab), use `LucideIcon`.

```ts
import { LucideIcon } from "@yamada-ui/react"
```

```tsx preview
<LucideIcon iconNode={burger} />
```

### Dynamic rendering

For dynamic rendering, use `DynamicIcon`.

:::warning
Although you can load icons using `DynamicIcon`, it is not recommended because all icons are imported at build time. Since icons are loaded dynamically, they may flicker while loading.
:::

```ts
import { DynamicIcon } from "@yamada-ui/react/components/icon/dynamic"
```

```tsx
<DynamicIcon name="ghost" />
```

Icons load asynchronously, so there may be a delay before they are displayed. To display an element while an icon is loading, use `fallback`. If omitted, nothing is displayed until the icon loads.

```tsx
<DynamicIcon fallback={() => <Loading.Oval />} name="ghost" />
```

## Accessibility

If you set `aria-hidden={false}` and `aria-label` on `Icon`, `LucideIcon`, or `DynamicIcon`, it will be read by screen readers.

```tsx
<Icon as={FaRobot} aria-hidden={false} aria-label="Robot" />
```

### ARIA Roles and Attributes

| Element       | Roles and Attributes | Usage                                             |
| ------------- | -------------------- | ------------------------------------------------- |
| `svg.ui-icon` | `role="img"`         | Indicates that this is an image.                  |
|               | `aria-hidden`        | Excludes the element from the accessibility tree. |
