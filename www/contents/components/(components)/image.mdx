## Usage

:::code-group

```tsx [package]

```

```tsx [alias]
import { Image } from "@/components/ui"
```

```tsx [monorepo]
import { Image } from "@workspaces/ui"
```

:::

```tsx
<Image />
```

If your framework provides an image component, extend it with `styled`. For integration details, see the [documentation for each framework](/docs/get-started#pick-your-framework).

:::

:::
