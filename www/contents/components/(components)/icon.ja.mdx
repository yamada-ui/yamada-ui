## 使い方

:::code-group

```tsx [package]
import { GhostIcon } from "@yamada-ui/react"
```

```tsx [alias]
import { GhostIcon } from "@/components/ui"
```

```tsx [monorepo]
import { GhostIcon } from "@workspaces/ui"
```

:::

```tsx
<GhostIcon />
```

[こちら](/icons)から提供しているすべてのアイコンを探すことができます。

:::tip
データの読み込み中などの待機状態を表示する場合は、[Loading](/docs/components/loading)を使用します。
:::

:::tip
アイコンでユーザーの操作が必要な場合は、[IconButton](/docs/components/icon-button)を使用します。
:::

### React Iconsを使う

[React Icons](https://react-icons.github.io/react-icons)を使う場合は、`as`にコンポーネントをセットします。

```ts
import { Icon } from "@yamada-ui/react"
import { FaRobot } from "react-icons/fa"
```

```tsx
<Icon as={FaRobot} />
```

### Lucide labを使う

[Lucide lab](https://github.com/lucide-icons/lucide-lab)のアイコンを使う場合は、`LucideIcon`を使用します。

```ts
import { LucideIcon } from "@yamada-ui/react"
```

```tsx preview
<LucideIcon iconNode={burger} />
```

### 動的に表示する

動的に表示する場合は、`DynamicIcon`を使用します。

:::warning
`DynamicIcon`を使用してアイコンを読み込むことは可能ですが、ビルド時にすべてのアイコンがインポートされるため、推奨されません。アイコンは動的に読み込まれるため、読み込み時にアイコンが点滅することがあります。
:::

```ts
import { DynamicIcon } from "@yamada-ui/react/components/icon/dynamic"
```

```tsx
<DynamicIcon name="ghost" />
```

アイコンは非同期で読み込まれるため、表示までに遅延が発生する場合があります。読み込み中に要素を表示する場合は、`fallback`を使用します。省略した場合は、読み込みが完了するまで何も表示されません。

```tsx
<DynamicIcon fallback={() => <Loading.Oval />} name="ghost" />
```

## アクセシビリティ

`Icon`、`LucideIcon`、`DynamicIcon`に`aria-hidden={false}`と`aria-label`を設定すると、スクリーンリーダーによって読み上げられます。

```tsx
<Icon as={FaRobot} aria-hidden={false} aria-label="ロボット" />
```

### ARIAロールと属性

| 要素          | ロールと属性  | 使い方                                       |
| ------------- | ------------- | -------------------------------------------- |
| `svg.ui-icon` | `role="img"`  | 画像であることを示します。                   |
|               | `aria-hidden` | 要素をアクセシビリティツリーから除外します。 |
