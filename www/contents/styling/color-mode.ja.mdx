## 概要

Yamada UIには、アプリケーションのカラーモードを管理するためのサポートが組み込まれており、簡単にライトモードとダークモードを切り替えることができます。また、提供しているすべてのコンポーネントは、ダークモードをサポートしています。

:::info
デフォルトのカラーモードを変更する場合は、[カラーモード](/docs/theming/color-mode)をご覧ください。
:::

## 使い方

カラーモードを[Style Props](/docs/styling/style-props)に適用するには、配列を設定します。

- 最初の要素にライトモードの値を設定します。
- 最後の要素にダークモードの値を設定します。

```tsx preview
<Box p="md" bg={["success", "warning"]} color="white">
  Box
</Box>
```

## スコープ

`ColorModeScope`を使用すると、ドキュメントのカラーモードを変更せずに、単一の子要素とその子孫（ポータルに描画される要素を含む）で、指定したモードに応じたCSSトークンを使用できます。スコープが入れ子になっている場合は、最も内側のスコープのモードが適用されます。

```tsx preview
<ColorModeScope colorMode="dark">
  <Box w="full" p="md" bg="bg" color="fg">
    ダークモードのトークン
  </Box>
</ColorModeScope>
```

[`useColorMode`](/docs/hooks/use-color-mode)と[`useColorModeValue`](/docs/hooks/use-color-mode-value)は、引き続きアプリケーションのプロバイダーが提供するモードを参照します。`_dark`と`_light`のスタイル条件は、スコープの外側にある祖先要素にも一致します。例えば、ドキュメントがダークモードの場合、ライトモードのスコープ内にある子孫要素にも`_dark`が適用されることがあります。スコープのモードに合わせてスタイルを切り替えるには、セマンティックトークンを使用してください。

## ユーティリティ

Yamada UIには、カラーモードの便利なカスタムフックを提供しています。

:::
:::card{title="useColorModeValue" href="/docs/hooks/use-color-mode-value"}

提供された値から現在のカラーモードの値を返すカスタムフックです。
