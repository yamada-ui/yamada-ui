## 使い方

:::code-group

```tsx [package]
import { Image } from "@yamada-ui/react"
```

```tsx [alias]
import { Image } from "@/components/ui"
```

```tsx [monorepo]
import { Image } from "@workspaces/ui"
```

:::

```tsx
<Image />
```

:::tip
フレームワークが画像コンポーネントを提供している場合は、そのコンポーネントを`styled`で拡張して使用します。統合方法は、[各フレームワークのドキュメント](/docs/get-started#pick-your-framework)をご覧ください。
:::

:::tip
異なる表示やデバイスのシナリオに応じて代替の画像を提供する場合は、[Picture](/docs/components/picture)を使用します。
:::

:::tip
ユーザーを表すプロフィール写真やイニシャルのアイコンを表示する場合は、[Avatar](/docs/components/avatar)を使用します。
:::
